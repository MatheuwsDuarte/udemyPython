Este repositório contém os materiais de estudo, exercícios e projetos práticos desenvolvidos durante o curso **"Programação Python do Zero a Inteligência Artificial 2026"**, ministrado por Andre Iacono. O conteúdo abrange desde a lógica inicial até automação em nuvem e ciência de dados.

## 📂 Estrutura do Repositório

O projeto está organizado nas seguintes categorias, conforme o progresso no curso:

| Pasta | Conteúdo Principal | Destaques / Arquivos |
| :--- | :--- | :--- |
| **`FundamentosPython`** | Lógica e Sintaxe | Base da linguagem e conceitos essenciais. |
| **`DesafiosPy`** | Exercícios Práticos | Resolução de problemas para fixação de lógica. |
| **`POO`** | Orientação a Objetos | Herança múltipla, Polimorfismo e Agregação. |
| **`Projetos-Py`** | Aplicações Funcionais | Calculadoras (IMC/Pintura), Ponto do Steak e Filtros. |
| **`DataScience`** | Análise de Dados | Manipulação de datasets (Casas/FIFA) com **Pandas** e **NumPy**. |
| **`AutomacaoAWS`** | Automação Cloud | Scripts para integração e tarefas automáticas na AWS. |

## 🛠 Tecnologias e Bibliotecas Utilizadas

* **Linguagem Principal:** Python 3.12
* **Análise e Manipulação de Dados:** **Pandas**, NumPy
* **Visualização de Dados:** Matplotlib
* **Automação:** Scripts para ambiente AWS 
* **Paradigmas:** Programação Orientada a Objetos (POO)
